## Procedure

1. Switch ON the power supply.
2. Switch ON the MCB ON/OFF switch.
3. Press the start button S<sub>1</sub>. Now start LED glows.
4. Change the current value using current adjustment knob provided on the left side of the Relay setup module.
5. After setting the fault current then press the stop button S<sub>2</sub> and also press the reset button of the stop clock to make the displayed time to zero.
6. Now press the start button S<sub>1</sub>. The stop clock starts counting and when relay trips, it stops counting. During the interval the disc in the relay will rotate.
7. When the relay coil trips, the disc returns to the normal (original) position. Note down the relay current from the Relay-current meter and trip time from the stop clock.
8. Repeat the above procedure from step 5 for various fault currents.
